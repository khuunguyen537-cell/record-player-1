# 🎵 Arduino Record Player Project

This team project simulates a simple record player using Arduino playing Mary has a little lamb. 

## Features
- Plays melody using a speaker
- Controlled by a switch
- Uses PWM for sound output

## Components
- Arduino board
- Speaker
- Switch
- Wires

## Files
- `record_player.ino` – main Arduino code

## How to Run
1. Upload code to Arduino
2. Connect speaker to pin 2
3. Connect switch to pin 3
4. Power on and enjoy

## Notes
Includes predefined melody using frequency arrays.
